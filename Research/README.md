# Research Notes

Use this folder for experiments related to native WhatsApp migration feasibility.

## Rules

- Use only test accounts/devices and disposable test data where possible.
- Never experiment on the only copy of a user's chats.
- Do not store real chat exports, media, credentials, OTPs, or personal information in Git.
- Keep prototypes isolated from production transfer code.
- Record exact OS/app versions and repeatable steps.
- Link to official documentation and distinguish verified facts from hypotheses.
